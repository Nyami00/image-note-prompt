# image-note-prompt

noteカバー画像（見出し画像）の**手動作成用メタプロンプト v1.0** を、貼るだけで組み立てられる静的ツール。

Notionの記事ページをコピーしてそのまま貼り付けると、`タイトル／カバーコピー／テーマ／本文` を自動で振り分けて、ChatGPT（画像生成）等にそのまま渡せるメタプロンプトを出力します。

## 使い方

1. ページを開き、Notionの記事をコピーして左上の欄に貼り付ける
2. 自動反映された「タイトル／カバーコピー／テーマ」を確認（手修正OK・コピーは字数チェックつき）
3. 「メタプロンプトをコピー」→ ChatGPT等に貼って生成
4. 誤字があれば「修正用ワンライナー」を1回だけ送る（2回目も不一致なら画像なし公開で可）
5. noteの見出し画像に設定 → Notionを「カバー画像=作成済」に更新（コピー新規作成時は「カバーコピー」プロパティにも保存）

## GitHub Pages で公開する

1. このブランチを `main` にマージ
2. リポジトリの **Settings → Pages → Build and deployment** で
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` を選択して Save
3. 数分後に `https://nyami00.github.io/image-note-prompt/` で公開されます

## 設計

- デザインシステム：カバー画像係v2正本（2026-07-06改訂・ボールドタイポ×ダイナミック背景）と同一。自動生成分（v2/v3）とnoteフィード上で見た目が揃う
- v2で人間が事前に行う3判断（①コピー22字判定・短縮 ②テーマ→色 ③モチーフ選定）はAI側の【手順】に内蔵済み
- 依存ライブラリなしの単一 `index.html`（オフラインでも動作）
